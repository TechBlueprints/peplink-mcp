# peplink-mcp

A [Model Context Protocol (MCP)](https://modelcontextprotocol.io) server for interacting with Peplink devices and the Peplink InControl2 cloud management platform.

## Overview

`peplink-mcp` exposes Peplink device management and telemetry capabilities to AI assistants and other MCP-compatible clients. It targets the Peplink router API and, where applicable, the InControl2 API.
